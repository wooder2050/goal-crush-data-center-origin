# 파워랭킹 공식 (Power Index)

## 개요

골때녀 데이터센터의 선수 파워랭킹은 포지션별 가중치를 적용한 복합 지수(0~100점)입니다.

**경기 단위 계산**: 각 경기마다 해당 경기의 포지션 공식으로 개별 PI를 계산한 뒤, 시즌 전체 경기의 **PI 평균**을 최종 점수로 사용합니다. 이를 통해 경기마다 포지션이 달라지는 선수도 정확하게 평가됩니다.

## 대상

- 현재 시즌에 **1경기 이상 출전**한 선수
- **평점 데이터(player_match_ratings)가 있는 경기만** 집계

## 포지션별 가중치

| 지표         | FW      | MF      | DF      | GK      | 경기별 정규화 방식                            |
| ------------ | ------- | ------- | ------- | ------- | --------------------------------------------- |
| 공격포인트   | **30**  | **25**  | **25**  | **5**   | `min(해당경기(골+도움)/4.0, 1.0)`             |
| 액션 점수    | **10**  | **10**  | **10**  | **10**  | `min(해당경기 액션점수/80.0, 1.0)`            |
| 승리         | **15**  | **15**  | **15**  | **15**  | 승리=1.0, 패배=0.0                            |
| stats 평점   | **20**  | **25**  | **25**  | **10**  | `해당경기 평점/10.0`                          |
| xT 평점      | **25**  | **25**  | **20**  | **10**  | `해당경기 xT평점/10.0`                        |
| 클린시트     | -       | -       | **5**   | **20**  | 무실점=1.0, 실점=0.0                          |
| 실점 역수    | -       | -       | -       | **15**  | `1/(1+해당경기 실점)` (GK 교체출전 시 ×0.5)   |
| 세이브성공률 | -       | -       | -       | **15**  | `해당경기 성공세이브/총세이브` (교체 시 ×0.5) |
| **합계**     | **100** | **100** | **100** | **100** |                                               |

## 정규화 기준값

| 지표                 | 만점 기준 | 설명                                    |
| -------------------- | --------- | --------------------------------------- |
| 경기당 공격포인트    | 4.0       | 경기당 4점(예: 2골 2도움) 이상이면 만점 |
| 경기당 액션 점수     | 80.0      | 경기당 80점 이상이면 만점               |
| 평점                 | 10.0      | 10점 만점 기준                          |
| 승률/클린시트/세이브 | 1.0       | 비율 그대로 (0~1)                       |

## 계산 방식

1. 각 경기마다 해당 경기의 **포지션 공식**으로 PI를 개별 계산
2. 시즌 전체 경기의 **PI 평균**이 최종 파워 인덱스

### GK 교체 출전 보정

GK로 교체 투입(20분 미만 출전)된 경기는 GK 전용 지표(클린시트, 실점역수, 세이브성공률)에 **×0.5 보정**을 적용합니다. 선발(풀타임)은 보정 없이 100% 반영됩니다.

### 포지션 표기

경기마다 뛴 포지션이 다를 수 있으며, 출전 횟수 순으로 모든 포지션을 표기합니다.
예: 2경기 DF + 1경기 FW → `DF/FW`

## 데이터 소스

- `player_match_stats` — 출전, 골, 도움, 실점, 포지션
- `player_match_ratings` — stats 평점 (INNER JOIN, 없는 경기 제외)
- `player_match_xt_ratings` — xT 평점
- `match_actions` — 액션 점수, 세이브
- `matches` — 승패 판정, 클린시트

## 업데이트 주기

- 매 라운드 경기 종료 후 자동 재계산
- 평점 데이터 입력 후 반영
